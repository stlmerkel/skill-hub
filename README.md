# skill-hub

skill-hub is a starter kit for standing up your own agent-skill marketplace: QA-gated `SKILL.md` packages, semantic releases, a static marketplace page, and install paths for Claude Code, Cursor, and GitHub Copilot. The kit's manual is [KIT.md](KIT.md).

If this is your hub, replace this file with your hub's own front page; skill-hub never changes it.
